# Mothline

A night-courier arcade game: steer a moth along a dark ridge, collect glowing seed hauls, and keep
your wings light enough to dodge the rocks that close in as the night deepens. Bigger hauls score
more and make you heavier, so every greedy run is a gamble.

Open `game/index.html` in desktop Chrome. No build step, no network requests, no external libraries.
